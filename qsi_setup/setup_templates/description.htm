Welcome to TunePerf Setup

TunePerf is an intelligent, hardware-aware system optimizer and orchestration utility designed for Linux, Q4OS, and the Trinity Desktop Environment (TDE).

Key Features:

  • Topology-Aware Optimization: Dynamically scales kernel and memory settings based on your exact CPU and RAM capacity.
  • Zero Resident Daemon: Executes as a lightweight one-shot payload at boot with zero background resource overhead.
  • Deep Kernel & EEVDF Tuning: Direct tuning for modern schedulers, ZRAM compression streams, and SystemD global limits.
  • Native TDE Desktop GUI: Multi-language client for interactive profiles, fine-grained control, and live monitoring.
  • Safe & Fully Reversible: Built-in automatic backup engine with atomic state rollback.
